# 🤖 Shimeji  
![](https://img.shields.io/badge/Version-v1.0.4-green.svg)  

✨ 基于 Shimeji ee 项目构建的个人桌宠小项目  

---

## 🚀 运行及打包方法

### 💻 开发运行
1. 运行 `Main.java` 内的 `main` 方法以启动项目。

### 📦 Maven 打包
1. 执行 `mvn clean install` 进行项目打包。

> ⚠️ **注意**：如需要在 IDE 中开发/调试程序，请添加 VM 参数：`-Ddev=true`

### 🎮 直接运行 Demo
1. 📥 下载项目 zip 压缩包
2. ☕ 配置 JRE 运行环境（已有环境请忽略）
3. 📂 打开 `demo` 文件夹，双击运行 `shimeji.jar` 或 "点我运行.cmd" 即可成功运行项目 demo
4. ℹ️ Demo 版本为 1.0.4 版，支持在线更新。除非后续对更新功能进行了大幅度修改（会在此备注），需要重新下载完整包，否则均可通过在线更新完成更新
